# 插件: 清华云盘(cloud)

把清华云盘(cloud.tsinghua.edu.cn)的**分享链接**挂载为课程资源: 粘贴一个多课程资料库的分享链接, 浏览其目录树, 与本地课程同名的目录自动匹配, 一键把匹配目录登记为对应课程的链接资源. 属 network 插件: **默认禁用, 启用即授权联网**.

特点:

- **免登录**: 只读取公开分享链接(任何人持有链接即可访问), 不需要校园账户, 与 campus/learn 插件相互独立
- **不整库下载**: 只登记目录链接(引用式索引), 双击资源经系统浏览器打开云盘对应目录
- 目录匹配规则: 目录名与课程名 全等 > 前缀互含 > 互含(如 `核仪器原理` 与 `核仪器原理(2026)` 视为同课)

## 前提与启用

```bash
python cli.py plugin-enable cloud --yes
```

分享链接在云盘网页端创建: 选中资料库/目录 -> 共享 -> 创建链接 -> 复制"共享页面链接"(形如 `https://cloud.tsinghua.edu.cn/d/<分享id>/`).

## 浏览与挂载

```bash
python cli.py cloud-browse "https://cloud.tsinghua.edu.cn/d/<分享id>/"   # 只读预览: 目录 -> 课程匹配
python cli.py cloud-mount  "https://cloud.tsinghua.edu.cn/d/<分享id>/"   # 挂载: 匹配目录登记为课程链接资源
# 可选: --depth N 目录匹配递归层数(1-3, 默认 2; 多课程资料库的课程目录一般在第 2 层)
```

- `cloud-browse` 只读不留痕; `cloud-mount` 登记资源并留痕(`log` 可查)
- 匹配到的目录登记为 `link` 资源, 显示名即目录名, 出现在左栏课程空间; 双击经系统浏览器打开云盘目录
- 未匹配到课程的目录不动; 想挂载就先建同名课程再挂一次
- 重复挂载幂等: 同一链接在同一课程下已登记过时自动跳过
- 通用插件入口同样可用: `plugin-run cloud --set action=mount --set url=<分享链接>`

**GUI**: 中栏"云盘"页签, 粘贴链接 -> "浏览"预览匹配表(目录/匹配课程/状态) -> "挂载到课程"一键登记; 页签按需切换两态(未启用引导/主视图).

## 数据与隐私

- 不存任何凭据: 匿名访问公开分享, 程序内无登录态
- 浏览/挂载只访问 cloud.tsinghua.edu.cn; 登记的资源链接存本机 `data/shuimu.db`
- 分享链接被云盘端取消或过期后, 已登记资源仍在(双击打开时云盘会提示), 可随时"移除选中"清理索引
